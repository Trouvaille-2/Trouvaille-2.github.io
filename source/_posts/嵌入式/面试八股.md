# c语言

1.什么是函数指针，什么是指针函数？

>函数指针：指向一个函数的指针
>指针函数：返回值为指针的函数

2.指针的大小

>指针的大小和编译器的位数有关，在32bit的系统下指针的大小是4个字节，在64bit的系统下指针是8个字节。
>指针的大小是固定的，和类型无关。

3.sizeof和strlen的区别

>sizeof是一个运算符，strlen是一个函数，包含string.h
>sizeof计算的是所占内存的大小，strlen计算的是字符串的长度
>strlen一般用于字符串的长度计算，sizeof可以计算int float

4.数组指针和指针数组的区别

>数组指针本质是指针，这个指针指向数组
>指针数组本质上是一个数组，里面的每一个数组都是指针

1.  volatile 作用？ 
告诉编译器不要优化，变量可能由硬件/中断修改，每次都要从真实地址读取。
2.  static 作用？ 
局部static：生命周期延长到整个程序运行，只初始化一次。
全局static：只能在本文件访问，外部不可见。
3.  const 作用？ 
定义只读变量，不能修改，常用于保护参数、寄存器配置。
4.  指针和数组区别？ 
数组名是地址常量，不能自增；指针是变量，可以++/--。
5.  define 和 typedef 区别？ 
define是单纯替换，不检查类型；typedef是给类型起别名，安全。
6.  结构体对齐？ 
编译器按成员最大类型对齐，为了CPU访问效率，会有空字节。
7.  堆和栈区别？ 
栈：自动分配释放，速度快，空间小。
堆：malloc/free，手动管理，空间大，容易内存泄漏。
8.  strcpy 手写思路？ 
判断空指针，循环拷贝，最后加'\0'。
9.  中断服务函数注意什么？ 
代码尽量短、不延时、不打印、不执行耗时操作、慎用全局变量。
10.  什么是野指针？ 
指向非法内存的指针，没初始化、已释放的指针，会导致程序崩溃。
# 二、STM32核心
1.  用任何外设第一步做什么？ 
使能对应时钟。
2.  GPIO 四种输入模式？ 
上拉输入、下拉输入、浮空输入、模拟输入。
3.  GPIO 两种输出模式？ 
推挽（强高低）、开漏（需要外部上拉，可实现电平兼容）。
4.  中断优先级两种？ 
抢占优先级：高的可以打断低的。
子优先级：都不能打断，谁高先执行。
5.  NVIC 是什么？ 
嵌套向量中断控制器，管理中断优先级、使能、响应。
6.  USART 串口乱码原因？ 
时钟不对、波特率不匹配、电平不匹配、引脚配置错。
7.  DMA 好处？ 
不占用CPU，搬运数据，提高效率。
8.  PWM 用什么外设？ 
定时器。
9.  PWM 三要素？ 
频率、占空比、极性。
10.  看门狗作用？ 
程序跑飞、死机时自动复位。
11.  ADC 作用？ 
模拟量转数字量，采集电压。
12.  I2C 几根线？ 
SCL时钟 + SDA数据，半双工。
13.  SPI 几根线？ 
SCK、MOSI、MISO、CS，全双工，速度快。
14.  STM32 复位来源？ 
上电复位、手动复位、看门狗复位。
15.  HAL库和标准库区别？ 
HAL库跨芯片、易用；标准库针对性强、效率高。
# 三、RTOS（小厂只考简单）
1.  任务是什么？ 
独立运行的函数，有自己栈。
2.  临界区是什么？ 
不能被打断的代码段，保护共享资源。
3.  信号量作用？ 
同步、互斥，保护资源不被同时访问。
